# XLegal Documentation

This folder contains seed documents for legal architecture, traceability, and
assumption management.

## Documents

- [X_LEGAL_COMPASS.md](./X_LEGAL_COMPASS.md): mission statement and guiding principles.
- [LEGAL_ARCHITECTURE.md](./LEGAL_ARCHITECTURE.md): working model of legal-architecture primitives.
- [IMPLEMENTATION_PLAN.md](./IMPLEMENTATION_PLAN.md): phased plan before implementation.
- [LEGAL_GRAMMAR.md](./LEGAL_GRAMMAR.md): shared glossary for Treasury and Settlement vocabulary.
- [ARCHITECTURAL_INVARIANTS.md](./ARCHITECTURAL_INVARIANTS.md): proposed invariants and obligations.
- [REGULATORY_TRACEABILITY_MATRIX.md](./REGULATORY_TRACEABILITY_MATRIX.md): placeholder matrix for obligations and architecture.
- [ADVERSE_ARGUMENTS.md](./ADVERSE_ARGUMENTS.md): counterparty and regulatory skepticism model.
- [OPEN_QUESTIONS.md](./OPEN_QUESTIONS.md): unresolved legal/regulatory questions.

## Maintenance

Update these documents whenever legal reasoning, architecture assumptions, or
traceability needs change. Keep language explicit about uncertainty and open
issues.
