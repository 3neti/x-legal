# X-LEGAL Compass

XLegal exists to keep legal intent, regulatory constraints, architecture, and
implementation behavior traceable to each other.

## Mission

To ensure legal meaning is explicit before implementation decisions, and that future
code can be audited against legal and regulatory assumptions.

## Guiding principles

1. Substance over labels
2. Legal architecture before implementation architecture
3. No hidden wallet semantics
4. Every peso must have a mandate
5. Pay Code is a credential for an instruction, not stored monetary value
6. Uncertainty is documented, never hidden

## Operational posture

- Documentation-first decisions
- Interfaces over implementations
- Explicit open questions with owners and refresh cadence
- Minimal, auditable packages with constrained responsibilities

## Current state

- Scaffold created
- No legal conclusions treated as final
- No business/payment logic implemented
