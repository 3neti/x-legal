# Legal Grammar

| Term | Working definition |
| --- | --- |
| Treasury Mandate | A principal authorization that confines settlement behavior to agreed purposes. |
| Treasury and Settlement Agent | The entity receiving and executing treasury/settlement instructions under mandate. |
| Principal | The rights-holder for funds, whose mandate and instruction context is primary. |
| Client Funds | Funds traceable to a principal and restricted to authorized settlement use. |
| Treasury Position | A ledger construct tracking principal-facing exposure and movement. |
| Funding Instruction | Request that initiates or supports allocation of client funds. |
| Settlement Instruction | Formal instruction for a specific settlement action tied to a principal and purpose. |
| Lien | Evidence of reserved funds pending execution or reversal. |
| Reservation | Temporary hold against client funds for a specific instruction. |
| Pay Code | A redemption credential tied to a specific settlement instruction. |
| Redemption | The act of executing settlement against a valid Pay Code/instruction link. |
| Execution | Finalization of a settlement action consistent with mandate and obligations. |
| Expiration | Time-bound boundary where unresolved instructions require review and return flow. |
| Return of Unused Funds | Event that returns unspent client funds in a traceable manner. |
| Journal | Evidence record for traces, states, and material changes. |
| Legal Trace | A linked set of legal and regulatory references tied to package artifacts. |

## Vocabulary guardrails

- Avoid wallet/e-money-first definitions.
- Prefer operational verbs and mandate/instruction semantics.
