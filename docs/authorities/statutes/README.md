# Statutes

This folder is reserved for statutes and statutory excerpts that may affect the
legal architecture of x-change.

Statutory materials should be added with care. They must retain source provenance,
jurisdiction, status, and review notes in `../LEGAL_AUTHORITY_REGISTER.md`.

This folder should not become a general law library. It should contain only sources
that may shape the architecture, characterization, disclosures, controls, or
traceability obligations of the ecosystem.
