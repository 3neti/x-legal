# Knowledge

This directory is not an FAQ.

It is the institutional legal knowledge system of XLegal. Its purpose is to
preserve reasoning, not merely answers.

Future readers will include engineers, architects, product managers, internal legal
staff, external Philippine banking counsel, auditors, bank partners, regulators,
and future management. Those readers will need more than quick responses. They will
need to understand why a position exists, what supports it, what challenges it,
what remains uncertain, and how it evolved.

Knowledge Articles synthesize:

- Authorities.
- Characterization.
- Architectural invariants.
- Decision records.
- Traceability.
- Open questions.
- Implementation consequences.

The Knowledge System should eventually become the first place future lawyers begin
learning x-change. It should also help engineers understand why some architectural
choices are not mere implementation preferences, but legal-architecture commitments.
